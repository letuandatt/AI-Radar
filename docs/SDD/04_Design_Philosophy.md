# 4. Out of Scope

Để đảm bảo phạm vi phù hợp với đồ án cá nhân, các chức năng sau sẽ không được triển khai trong phiên bản đầu tiên.

* Dashboard Web
* Multi-user Authentication
* User Management
* Cloud Deployment Cluster
* Distributed Vector Database
* Fine-tuning LLM
* Multi-modal Retrieval
* Voice Assistant
* Real-time Streaming Pipeline

Những chức năng này được xem là hướng mở rộng cho các phiên bản tiếp theo.
