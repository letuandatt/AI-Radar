# Operations View

Operations View mô tả các khía cạnh liên quan đến việc vận hành, cấu hình và phát triển AI-Radar sau khi hệ thống được triển khai.

View này không mô tả nghiệp vụ mà tập trung vào các mối quan tâm ở mức vận hành (Operational Concerns).

---

# Documents

| Document | Description |
|-----------|-------------|
| `configuration.md` | Chiến lược quản lý cấu hình của hệ thống. |
| `error_handling.md` | Chiến lược xử lý lỗi và phục hồi. |
| `logging.md` | Chiến lược ghi log và quan sát hệ thống. |
| `deployment_view.md` | Góc nhìn triển khai và môi trường vận hành. |
| `scalability.md` | Khả năng mở rộng và giới hạn của kiến trúc. |
| `future_evolution.md` | Định hướng phát triển kiến trúc trong tương lai. |
